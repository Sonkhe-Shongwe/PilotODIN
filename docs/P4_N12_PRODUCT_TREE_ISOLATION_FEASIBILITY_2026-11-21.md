**Decision:** A restricted generated-writer test is a useful **control for the prevention mechanism**, but it is **not an application-relevant proof** until a separate, explicitly reviewed product launch design shows how confinement reaches the real Tauri parent, WebView2 browser/network children and both sidecars. No general token inheritance or system broker behavior may be assumed from source inspection. A restricted generated writer would not explain the existing 113 WebView-network out-of-scope mutations, 15 residual network path gaps, 4,112 background path gaps, 42 missing process lifetimes or 23 unsupported operations.
